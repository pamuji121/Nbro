# Ujian SMPN 45 Surabaya (WebView)

URL ujian : https://sas.smpnegeri45sby.sch.id/
PIN keluar: 45sby  (ubah di app/build.gradle.kts -> EXIT_PIN)

## Cara dapat APK (tanpa Android Studio)
1. Buat repository baru di github.com, upload SEMUA isi folder ini (termasuk folder .github).
2. Buka tab "Actions" -> workflow "Build APK" -> tunggu hijau (3-5 menit).
3. Klik run tersebut -> bagian "Artifacts" -> unduh "Ujian-SMPN45-APK" -> ekstrak -> app-debug.apk.
4. Kirim APK ke HP siswa, izinkan "Install dari sumber tidak dikenal", lalu install.

## Cara lain: Android Studio
File > Open > pilih folder ini > Build > Build APK(s).
